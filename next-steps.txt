================================================================================
CRITICAL: VIEWS vs EARNINGS
================================================================================

The most important distinction in social prediction markets:

❌ EARNINGS/REVENUE = NOT BETTABLE
   - YouTube revenue (RPM/CPM) is PRIVATE data
   - Only visible in creator's YouTube Studio dashboard
   - SocialBlade estimates show ranges like "$10K - $150K"
   - That margin of error is TOO WIDE to settle a bet
   - No oracle can verify this data
   
   EXCEPTION: Public company financials (FaZe Clan stock)

✅ VIEWS/METRICS = BETTABLE (Gold Standard)
   - View counts are PUBLIC (everyone can see)
   - Verifiable via YouTube Data API v3
   - Hard to fake at scale (YouTube audits)
   - Real-time updates (changes within minutes)
   - Perfect for velocity markets

ALWAYS ASK: "Can an API verify this?" If NO, don't create the market.
